# Учёт оборудования — локальная сеть

Однофайловое приложение (Windows .exe) с веб-интерфейсом для учёта оборудования
в локальной сети. Работает без внешней СУБД, без установки, без Node.js на
машине пользователя.

## Требования

**Для сборки:**
- Go 1.22+ (без CGO, gcc не нужен)
- Node.js 18+ и npm (для сборки фронтенда)

**Для запуска:**
- Windows 10/11 x64
- Ничего больше устанавливать не нужно

## Сборка

1. Установите Go и Node.js.
2. Запустите `build.bat` из папки проекта.
3. На выходе: `EquipmentTracker.exe` в корне проекта.
